# 실제 구글 시트 설치 점검표

모의 환경 테스트가 통과해도 실제 구글에서는 권한·배포 설정 때문에 달라질 수 있다. 판매 전에 **개인 구글 계정**의 빈 시트에서 직접 확인한다.

## 설치
1. 새 구글 시트 → 확장 프로그램 → Apps Script → `Code.gs` 붙여넣기
2. `setupSheets` 실행(권한 허용) → 탭 3개 생성 확인
3. `loadSampleData` 실행 → `품목` 탭에 9행
4. 배포 → 새 배포 → 웹 앱(실행: 나 / 액세스: 모든 사용자) → URL 복사
5. 브라우저에서 `URL?action=getAll` 열기 → JSON이 나오면 성공
6. `index.html`의 `SCRIPT_URL_HERE`를 URL로 교체 후 열기

## 기능
| # | 동작 | 기대 결과 |
|---|---|---|
| 1 | 앱 열기 | "연결됨", 샘플 9개 표시 |
| 2 | 품목 추가 | 시트에 행 추가 |
| 3 | 적정량 수정 | 시트 값 변경, 재고 유지 |
| 4 | 재고파악 저장 | 재고 변경 + `실사기록` 행 추가 |
| 5 | 청구서 생성 | `청구기록` 행 추가, 청구서 창 표시 |
| 6 | 새로고침 | 청구 이력·실사일 유지 |
| 7 | 품목 삭제 | 해당 행 삭제 |
| 8 | 스마트폰에서 열기 | 동일하게 동작 |

## 자주 나는 문제
- "연결 실패": 배포 액세스가 "모든 사용자"인지, 코드를 고친 뒤 **새 배포**를 했는지 확인
- "시트가 없다": `setupSheets` 먼저 실행
- 권한 화면에서 막힘: "고급 → 안전하지 않음(이동) → 허용"
