# 병원 홍보용 스틱맨 영상

업스트림 [`stickman-video-director`](https://github.com/kaomei/stickman-video-director)의 Director(A)/Autopilot(B) 워크플로를 그대로 사용하되, **병원 영상에 필요한 규칙만 덧씌운다.** 업스트림 규칙과 충돌하면 이 문서의 의료광고 규칙이 우선한다.

## 왜 스틱맨인가
- 환자 얼굴·신체가 나오지 않아 **초상권·개인정보 부담이 없다.**
- 수술 장면도 부담 없이 순화해 설명할 수 있다.
- 카메라·촬영 인력 없이 제작 가능.

## 작업 순서 (각 단계 끝에 반드시 확인 보고)

1. **병원 프로필 확인** — [hospital-profile-template.md](references/hospital-profile-template.md)의 항목이 비어 있으면 한 번에 모아서 질문한다. 이미 받은 값은 다시 묻지 않는다.
2. **영상 유형 선택** — [video-types.md](references/video-types.md) 참고 (병원 소개 / 질환·수술 안내 / 예방·재활 상식 / 입원·수술 전 준비 / 이벤트·공지).
3. **대본 작성** — 업스트림의 5단계 흐름을 병원용으로 변형한 [script-templates.md](references/script-templates.md) 사용.
4. **의료광고 검수 (필수 게이트)** — [medical-ad-compliance.md](references/medical-ad-compliance.md) 체크 + `scripts/check_medical_ad.py` 자동 검사. **통과 전에는 영상 프롬프트 단계로 넘어가지 않는다.**
5. **스타일·비율·길이 확정 후 업스트림 흐름 진행** — Director(A1~A5) 또는 Autopilot(B1)으로 스토리보드/프롬프트 생성. 병원 권장 설정은 아래 표.
6. **최종 재검수** — 완성 대본·자막·썸네일 문구를 다시 `check_medical_ad.py`로 검사. 영상에 들어가는 모든 글자가 대상.

> 사용자 선호: 작업이 하나 끝날 때마다 결과를 확인해 보고하고, 다음 단계로 넘어가기 전에 한 번 더 점검해 오류를 줄인다.

## 병원 권장 설정

| 항목 | 권장 | 이유 |
|---|---|---|
| 스타일 | A1 밝은 흰 배경(깔끔, 신뢰감) 또는 A4 따뜻한 일상(환자 공감) | 의료 이미지에 맞는 차분한 톤 |
| 스타일 비권장 | A3 선사시대 블랙코미디, A5 역사 카툰 | 의료 주제와 톤 불일치 |
| 비율 | 유튜브 16:9 / 쇼츠·릴스·병원 대기실 세로모니터 9:16 | 용도별 |
| 길이 | 소개 60초, 질환 안내 60~90초, 쇼츠 30초 | 정보 과다 방지 |
| 색상 | 병원 대표색 1개 + 흰/검정 (※ 생성 프롬프트에는 색 코드 대신 일반 색 이름 사용) | 업스트림 규칙 유지 |
| 나레이션 | 차분한 중저음. 업스트림 voice-continuity 규칙 적용 | 신뢰감 |
| BGM | 잔잔한 피아노/어쿠스틱 | 불안 유발 금지 |

## 반드시 지킬 병원 영상 규칙

- **진단·치료 효과를 단정하지 않는다.** "완치", "100%", "반드시 낫는다" 금지.
- **과장·비교·최상급 금지.** "최고", "유일", "타 병원보다" 등.
- **환자 치료 경험담·전후 비교 금지** (스틱맨이어도 '환자 후기 형식'은 금지).
- **마지막은 안내/예방 상식 + 방문 권유(진료시간·위치)** 로 마무리. 통증 공포 조장 금지.
- 수치·통계·출처 없는 주장은 넣지 않는다. 병원이 제공한 정보만 사용.
- 수술 장면은 **절개·출혈 등 혐오 표현 없이** 단계 설명 중심(진찰→검사→설명→수술→회복)으로 순화.
- 영상 속 문구(자막·썸네일)에도 동일 규칙 적용.

## 결과물 형식
- 기획서 1장(유형·대상·길이·핵심 메시지)
- 대본(한국어 나레이션 + 장면 설명)
- 의료광고 검수표(통과/수정 사유)
- 업스트림 Phase A 스토리보드 → 승인 → Phase B 프롬프트
- 게시용 문구(제목·설명·해시태그) — 이것도 검수 대상

## 한계 (정직하게 안내)
- 이 스킬은 **법률 자문이 아니다.** `check_medical_ad.py`는 대표적인 금지 표현을 걸러주는 보조 도구이며, 최종 게시 전 **병원 내 담당자/관할 보건소 사전심의 여부 확인**이 필요하다. (인터넷 매체·SNS 광고도 심의 대상 여부를 병원이 확인)
- 영상 생성(Gemini 등)과 렌더링은 업스트림 스킬이 요구하는 도구 설정이 있어야 한다.
