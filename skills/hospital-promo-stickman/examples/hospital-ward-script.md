# 병실 생활 안내 영상 (H1 병원 이용 안내) — 100초

근거: 병원 홈페이지 「병실 생활 안내」 화면 (원장님 제공 캡처, 8개 항목)
설정: 1920x1080, 100초(10장면 x 10초), 무음 + 한글 자막, 밝은 클래식 스틱맨, 병원 로고, 마지막 안내 카드(천안본정형외과)
항목이 8개라 항목당 10초씩 배정했습니다. 화면 위 **진행 띠**는 1~8번 동그라미이고 지금 항목 이름이 옆에 표시되며, 지나간 항목은 금색으로 남습니다.

## 장면과 자막

| 시간 | 항목 | 화면 | 자막 |
|---|---|---|---|
| 0~10s | 인트로 | 병실 침대 옆에 선 스틱맨, 제목 "병실 생활 안내" | 입원 중 병실 생활 안내입니다. / 여덟 가지를 알려 드립니다. |
| 10~20s | 1 기상 및 취침 | 해와 "오전 6:30", 달과 "오후 10:00", 규칙적 리듬 화살표 | 기상은 오전 6시 30분, 취침은 오후 10시입니다. / 안정적인 회복을 위해 규칙적인 생활 리듬을 유지해 주세요. |
| 20~30s | 2 식사 시간 | 식판 3개와 "오전 7:30 / 낮 12:00 / 오후 6:00", 식단표 | 식사는 아침 7시 30분, 점심 12시, 저녁 6시에 / 병실 또는 식당에서 제공됩니다. / 치료 계획에 맞춘 식단이 준비됩니다. |
| 30~40s | 3 병실 내 금지 사항 | 흡연·음주·소음 금지 표시, 외부 음식 반입 시 간호사 확인 | 병실 안 흡연과 음주는 엄격히 금지됩니다. / 큰 소리는 자제하고, 외부 음식은 간호사에게 먼저 확인해 주세요. |
| 40~50s | 4 개인 위생 관리 | 샤워 + 간호사와 일정 조율, 미끄럼 방지 슬리퍼 | 샤워와 목욕은 간호사와 일정을 조율해 진행합니다. / 낙상 예방을 위해 욕실에서는 미끄럼 방지 슬리퍼를 신어 주세요. |
| 50~60s | 5 귀중품 관리 | 보관함, 지갑이 보관함으로, 가족에게 맡기기, 분실 주의 표시 | 귀중품과 고액의 현금은 병원 보관함을 이용하거나 / 가족에게 맡겨 주세요. / 분실 시 병원은 책임지지 않으니 주의해 주세요. |
| 60~70s | 6 외출 및 외박 | 의사 허가 → 원무과 신청, 무단 외출·외박 금지 표시 | 외출·외박은 담당 의사의 허가를 받아 원무과에 신청해 주세요. / 무단 외출·외박은 치료에 지장을 줄 수 있습니다. |
| 70~80s | 7 침대 낙상 방지 | 침대 난간 올리기, 천천히 내려오기, 어지러우면 호출 버튼 | 이동할 때는 침대 난간을 올리고, 내려올 때는 천천히 움직여 주세요. / 어지러우면 혼자 이동하지 말고 호출 버튼을 눌러 주세요. |
| 80~90s | 8 응급 상황 대처 | 호출 버튼, 간호사 도착, 24시간 간호 인력 | 응급 상황에는 즉시 간호사 호출 버튼을 눌러 주세요. / 24시간 간호 인력이 상주하고 있습니다. |
| 90~100s | 마무리 | 병원 문 배웅, 안내 카드 | 궁금한 점은 병원으로 문의해 주세요. / 병실 생활 안내는 개인 상태에 따라 다를 수 있습니다. |

## 홈페이지 문구에서 바꾼 부분 (의료광고 검수)

| 홈페이지 원문 | 영상 문구 | 바꾼 이유 |
|---|---|---|
| 개인 체질과 치료 계획에 맞춘 **약선식단**이 준비됩니다 | 치료 계획에 맞춘 식단이 준비됩니다 | "약선"이 한방 식이요법·치료 효과를 암시할 수 있음 |
| 24시간 간호 인력이 상주하여 **신속하게 대응**합니다 | 24시간 간호 인력이 상주하고 있습니다 | 대응 수준을 앞세우는 표현 |
| 기상·취침·식사 시간, 금지 사항, 위생, 외출·외박, 낙상 방지 | 그대로 사용 | 병원 운영 안내 |

## 확인이 필요한 점
- 분실 책임 문구("병원은 책임지지 않으니")는 홈페이지의 병원 방침을 그대로 옮겼습니다. 법적 효력이 있는 문구이니 병원에서 한 번 확인해 주세요.
- 식사 시간, 기상·취침 시간, 병실·식당 제공 방식이 현재 병원 운영과 같은지 확인해 주세요.
- 홈페이지에도 "약선식단", "신속하게 대응" 표현이 있으니 점검을 권장합니다.
- 항목이 많아 자막이 빠르게 느껴질 수 있습니다. 100초보다 길게 해서 더 천천히 보여드릴 수도 있습니다.
- 사전심의 대상인지 확인해 주세요.
