# 퇴원 절차 안내 영상 (H1 병원 이용 안내) — 60초

근거: 병원 홈페이지 「퇴원 절차」 화면 (원장님 제공 캡처)
설정: 1920x1080, 60초(6장면), 무음 + 한글 자막, 밝은 클래식 스틱맨, 병원 로고, 마지막 안내 카드(천안본정형외과)
화면 위 **진행 띠**: 1 퇴원 상담 / 2 퇴원 수속 / 3 퇴원 후 관리 (지나간 단계는 금색으로 남음)

## 장면과 자막

| 시간 | 장면 | 자막 | 근거 |
|---|---|---|---|

| 10~20s | **1 퇴원 상담**: 의료진과 환자, 관리 방법·복약 지도·외래 일정 아이콘이 차례로 나타나 금색 체크 | 담당 의료진과 퇴원 후 관리 방법, / 복약 지도, 외래 진료 일정을 상담합니다. | 01 퇴원 상담 |

| 50~60s | 병원 문 앞 배웅, 안내 카드 | 궁금한 점은 병원으로 문의해 주세요. / 퇴원 안내는 개인 상태에 따라 다를 수 있습니다. | (이용 안내 문의 전화) |

## 제가 추가한 내용 (홈페이지에 없음 — 병원 확인 필요)

홈페이지 3단계만으로는 60초가 채워지지 않아 **누구에게나 해당되는 일반 안내**만 더했습니다. 병원의 실제 규칙은 넣지 않았습니다.

| 추가 내용 | 위치 | 판단 |
|---|---|---|
| 두고 가는 소지품이 없는지 한 번 더 확인 | 20~30s | 일반 안내. 병원이 별도 소지품 안내를 하고 있다면 알려주세요 |
| 퇴원 후 몸에 이상이 느껴지면 병원으로 문의 | 40~50s | 일반 안내. 문의 방법·시간(응급 포함)은 병원 기준이 있다면 반영해야 합니다 |
| 3단계 요약 | 40~50s | 홈페이지 내용을 다시 정리한 것 |

넣지 않은 것: 퇴원 시간, 퇴원 약 처방 내용, 진단서·서류 발급, 퇴원 후 주의사항(상처 관리, 운동 등), 응급 시 연락처 — 병원 규칙이나 의료 내용이라 확인 없이 쓰지 않았습니다.

## 홈페이지 문구 검수
- 홈페이지 문구는 광고 규정상 문제되는 표현이 없어 거의 그대로 썼습니다.
- "담당 의료진"은 홈페이지 표기를 그대로 두었습니다.
- 사전심의 대상인지 확인해 주세요.
