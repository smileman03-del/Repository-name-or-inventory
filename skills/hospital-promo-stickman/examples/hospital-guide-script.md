근거: 병원 홈페이지 「이용 안내 · 진료 절차」 화면 (원장님 제공 캡처)
설정: 1920x1080, 60초(6장면), 무음 + 한글 자막, 밝은 클래식 스틱맨, 병원 로고, 마지막 안내 카드(천안본정형외과)

화면 위쪽 **진행 띠**: 1 상담 예약 / 2 초진 상담 / 3 정밀 진단 / 4 치료 시작이 계속 보이고, 지나간 단계는 금색으로 채워져 남습니다.
