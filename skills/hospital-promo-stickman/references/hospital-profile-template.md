# 병원 프로필 (영상 제작 전 1회 작성)

비어 있는 항목은 질문해서 채운 뒤 재사용한다. **병원이 직접 제공한 정보만** 영상에 쓴다.

```yaml
hospital_name: 천안본정형외과      # 병원명 (확인 필요)
specialty: 정형외과
location: ""                        # 주소/오시는 길
phone: ""                           # 대표번호 (영상 하단 고지용)
hours: ""                           # 진료시간 / 휴진일
departments: []                     # 예: 관절, 척추, 재활, 도수치료
facilities: []                      # 예: MRI, 수술실, 입원실 (보유 사실만)
brand_color: ""                     # 일반 색 이름 (예: 짙은 파랑)
logo_use: false                     # 영상에 로고 삽입 여부
tone: 차분하고 신뢰감 있는         # 말투
target_audience: ""                 # 예: 50~70대 무릎 통증 환자, 직장인 목/허리
channel: []                         # youtube / shorts / 대기실 모니터 / 네이버 블로그
doctor_info_allowed: false          # 의료진 이름/경력 노출 여부 (경력은 사실 확인 필요)
```

## 확인 질문 (한 번에 묻기)
1. 영상 목적은? (병원 소개 / 질환 안내 / 예방 상식 / 수술 전 안내 / 공지)
2. 주제 1개 (예: 무릎 퇴행성 관절염 초기 관리)
3. 게시 채널과 비율(16:9 또는 9:16), 길이
4. 영상에 넣어도 되는 병원 정보(진료시간·위치·전화)
