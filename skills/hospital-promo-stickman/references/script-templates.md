# 병원용 대본 템플릿

업스트림의 5단계 감정 흐름(Hook → 통념 깨기 → 숨은 원리 → 핵심 진실 → 마무리)을 병원 톤으로 바꾼 것. 클립당 나레이션은 한국어 약 35~45자(10초) 기준으로 조정한다.

## H2 질환 안내 (60초 / 6클립)
1. **공감 훅 (0~10s)** — 질문형. 예: "계단 오를 때 무릎이 시큰거린 적 있으신가요?" (공포 조장 금지)
2. **흔한 오해 (10~20s)** — "참고 지내면 괜찮아진다고 생각하기 쉽습니다."
3. **원리 설명 (20~35s)** — 구조를 스틱맨 그림으로 단순 설명. 단정 표현 대신 "~할 수 있습니다".
4. **진료 과정 (35~45s)** — 진찰 → 검사 → 설명 → 치료 방향 상의. 결과 보장 금지.
5. **생활 관리 (45~55s)** — 일반적 예방 습관 1~2개 (병원 제공 정보 한정).
6. **마무리 (55~60s)** — "증상이 계속되면 전문의와 상담해 보세요." + 진료시간/전화 고지.

## H3 쇼츠 (30초 / 3클립)
1. 잘못된 습관 장면 (0~10s)  2. 올바른 방법 (10~20s)  3. 오늘의 한 가지 + 상담 권유 (20~30s)

## 나레이션 문체
- 존댓말, 단정 대신 가능성: "~할 수 있습니다", "~하는 경우가 있습니다".
- 전문용어는 괄호 없이 쉬운 말로 풀어쓴다.
- 마지막 고지 예: "치료 결과는 개인에 따라 다를 수 있습니다. 정확한 진단은 의료진과 상담하세요."

## 장면 연출 팁 (스틱맨)
- 통증은 빨간 작은 표시(번쩍임) 정도로만 표현, 신체 훼손 묘사 금지.
- 수술실 = 깔끔한 흰 방 + 의료진 실루엣 스틱맨, 도구는 단순 아이콘.
- 회복 = 걷기·계단·산책 등 일상 복귀 장면 (단, "완전히 회복" 단정 금지).
