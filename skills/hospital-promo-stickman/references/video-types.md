# 병원 영상 유형

| 코드 | 유형 | 길이/비율 | 핵심 구성 |
|---|---|---|---|
| H1 | 병원 소개 | 60s, 16:9 | 병원 한 줄 소개 → 진료과목 → 시설 → 오시는 길/진료시간 |
| H2 | 질환·수술 안내 | 60~90s | 증상 공감 → 흔한 오해 → 진료 과정 → 일반적 관리법 → 내원 권유 |
| H3 | 예방·재활 상식 | 30~60s, 9:16 | 잘못된 자세 → 올바른 자세 → 오늘 해볼 습관 1개 |
| H4 | 입원·수술 전 준비 | 60s | 준비물 → 금식/복용약 확인(※의료진 지시 우선) → 당일 흐름 → 문의처 |
| H5 | 공지·휴진·이벤트 | 15~30s | 날짜·내용 → 문의처 (이벤트는 환자 유인 규정 주의) |

## H2/H4 공통 주의
- 수술 방법·기간·회복은 **병원이 제공한 내용만**, "개인에 따라 다를 수 있습니다" 고지 포함.
- 약 복용/금식 등은 **"반드시 담당 의료진의 안내를 따르세요"** 로 마무리.
- 부작용·위험 정보를 숨기지 않는다 (공정한 정보 제공).
