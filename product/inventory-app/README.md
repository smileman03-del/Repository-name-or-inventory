# 병원 소모품 재고관리 시스템 PRO (구글 시트 + 스마트폰 앱)

병원 현장에서 쓰는 소모품 재고관리 앱입니다. 구글 시트를 장부로 쓰고, 스마트폰에서 **재고 확인 · 물품 청구서(인쇄) · 입고 · 정기 재고파악 · 품목 관리**를 할 수 있습니다.
별도 서버나 월 비용이 없고, 데이터는 사용자의 구글 시트에만 저장됩니다.

```
[구글 시트 (탭 4개)] ↔ [Apps Script (Code.gs)] ↔ [스마트폰 앱 (index.html)]
```

## 파일 구성
| 파일 | 역할 |
|---|---|
| `Code.gs` | 구글 시트 메뉴 + 앱과 통신하는 API |
| `index.html` | 스마트폰 앱 (파일 하나로 동작) |
| `README.md` | 이 설명서 |

필요한 것: 구글 계정, GitHub 계정(무료, 앱을 인터넷에 올릴 때 사용), 스마트폰 또는 PC 브라우저. 설치 시간은 약 25분입니다.

## 앱 화면 (아래 메뉴 5개)
밝은 화면과 어두운 화면(휴대폰의 다크 모드 설정을 따라감)을 모두 지원합니다.

- **재고현황**: 오늘의 정상 비율, 전체·정상·부족 개수. 부서 버튼에 **부족 개수가 빨간 숫자로** 표시되고, 품목마다 **적정재고 대비 막대**가 있어 부족한 품목이 한눈에 보입니다. 대분류·소분류 필터, 검색, **"부족만 보기"** 와 "부족 N개 청구하러 가기" 바로가기가 있습니다.
- **물품청구**: 재고부족 품목이 자동으로 나타납니다. 체크하고 수량(−/+)을 조정해 청구서를 만들고, **인쇄 / PDF 저장**으로 담당·팀장·승인 결재란이 있는 A4 문서를 바로 뽑을 수 있습니다. 지난 청구 내역에는 **입고 전 / 일부 입고 / 입고 완료** 상태가 표시됩니다.
- **입고**: 물품이 들어오면 재고에 **더해서** 기록합니다. ① **청구서 기준** — 입고 대기 청구서를 열면 남은 수량이 미리 채워져 있어 확인만 하면 되고, 나눠서 들어와도 누적됩니다. ② **직접 입고** — 청구서 없이 들어온 물품을 품목별로 입력합니다. 입고처·납품서 번호를 메모로 남길 수 있고, 입고 전·후 재고가 기록됩니다.
- **재고파악**: 대분류별 정기 실사. 부서마다 **D-day / 지남 / 미실시** 상태가 보이고, 최근 실사일과 **다음 실사 예정일**이 표시되며 예정일이 지나면 빨갛게 알려 줍니다. 수량을 바꾸면 바뀐 줄이 강조되고 저장 버튼에 "N건 변경"이 표시됩니다. 수량이 모두 그대로여도 "변경 없이 실사 완료"로 기록해 다음 실사일이 계산됩니다.
- **품목관리**: 품목 추가·수정·삭제, 적정재고·현재고 바로 수정, 소분류 일괄 변경, 메모

> **재고파악과 입고의 차이** — 재고파악은 세어 본 수량으로 현재재고를 **덮어씁니다**(실사). 입고는 들어온 수량을 현재재고에 **더합니다**.

## 구글 시트 상단 메뉴 (PC)
시트를 열면 상단에 **🏥 재고관리** 메뉴가 생깁니다.

| 메뉴 | 하는 일 |
|---|---|
| 📊 현황 대시보드 | 전체·재고부족·정상 개수와 대분류별 부족 현황을 보여 줍니다 |
| 📋 물품 청구서 생성 (부족 품목 전체) | 재고부족 품목 전체를 적정재고−현재재고 수량으로 한 번에 청구합니다 |
| 📅 실사 완료 기록 | PC에서 시트의 현재재고를 직접 고친 뒤, 대분류별 실사일을 남깁니다 |
| 🔢 품목번호 채우기 | 새로 붙여넣은 줄에 품목번호를 채웁니다 (앱을 열어도 자동으로 채워집니다) |
| 🧹 예제 데이터 지우기 | 예제 품목과 체험 기록(실사·청구서·입고)을 한 번에 지웁니다 |

## 구글 시트의 탭 4개
설치하면 자동으로 만들어지니 직접 만들 필요가 없습니다. **탭 이름은 바꾸지 마세요.**

| 탭 | 내용 | 직접 입력? |
|---|---|---|
| `품목 마스터` | 우리 병원 품목 목록. 열: 대분류(부서) / 소분류 / 품목명 / 규격·단위 / 적정재고 / 현재재고 / 메모 / 품목번호(자동) / 상태(자동) | **A~G열에 입력합니다.** H(품목번호)와 I(상태)는 자동이니 건드리지 마세요. |
| `실사 기록` | 실사할 때마다 날짜·대분류·변경 건수·변경 내역(이전→이후)이 쌓입니다 | 자동 기록 |
| `물품 청구서` | 만든 청구서가 청구번호별로 쌓입니다 | 자동 기록 |
| `입고 기록` | 입고할 때마다 입고일·청구번호·품목·입고수량·입고 전/후 재고·메모가 쌓입니다 | 자동 기록 |

## 설치 순서

### 1. 구글 시트와 Apps Script 준비
1. 브라우저에 `sheets.new` 를 입력해 새 구글 시트를 만듭니다.
2. **확장 프로그램 → Apps Script** 를 엽니다.
3. 기존 코드를 모두 지우고 `Code.gs` 내용을 붙여넣은 뒤 저장(Ctrl+S)합니다.

### 2. 탭 만들기 (아래 둘 중 하나)
상단의 함수 선택 칸에서 함수를 고르고 ▶ 실행을 누릅니다.
- **`loadSampleData`** : 예제 품목 15개가 들어 있는 상태로 시작합니다. 먼저 체험해 보고 싶을 때 추천합니다.
- **`setupSheets`** : 빈 상태로 시작합니다.

처음 실행하면 권한 승인 창이 뜹니다. **"고급 → 안전하지 않음(이동) → 허용"** 을 차례로 누르세요. 끝나면 구글 시트에 탭 4개가 생기고, 시트를 새로고침하면 상단에 🏥 재고관리 메뉴가 나타납니다.

### 3. 웹 앱으로 배포
1. **배포 → 새 배포 → 톱니바퀴 → 웹 앱**
2. 실행 사용자: **나** / 액세스 권한: **모든 사용자** (반드시)
3. 배포를 누르면 나오는 **웹 앱 URL을 복사**해 메모장에 저장합니다.

**연결 테스트**: 브라우저 주소창에 `복사한URL?action=getAll` 을 열었을 때 품목 데이터(JSON)가 보이면 성공입니다.

### 4. 앱에 URL 연결
`index.html` 을 메모장으로 열어 `SCRIPT_URL_HERE` 를 복사한 URL로 바꾸고 저장합니다. 메모장의 "모두 바꾸기"를 써도 됩니다.
```js
const SCRIPT_URL = "https://script.google.com/macros/s/....../exec";
```
같은 파일 위쪽의 **설정** 부분도 원하면 고쳐 주세요. (선택)
```js
const ORG_NAME = "";               // 화면 제목과 청구서에 표시할 병원 이름. 예: "○○병원"
const AUDIT_INTERVAL_DAYS = 14;    // 정기 재고파악 주기(일). 14 = 2주마다
```

### 5. 앱을 인터넷에 올리기 (GitHub Pages, 무료)
스마트폰에서 열려면 `index.html` 이 인터넷 주소를 가져야 합니다. 아래 방법은 GitHub Pages를 쓰는 예시이며, **내 GitHub 계정에 내 저장소를 새로 만듭니다.** (판매자의 저장소를 쓰지 않습니다.)

**A. GitHub 계정 만들기** — `github.com` → Sign up (이미 있으면 Sign in)

**B. 저장소 만들기**
1. 오른쪽 위 **+** → **New repository**
2. Repository name: 영문으로 입력 (예: `inventory-app`)
3. **Public** 선택 (무료 Pages는 Public 저장소가 필요합니다)
4. **Create repository**

**C. `index.html` 올리기** — 반드시 **4단계에서 URL을 넣어 저장한 파일**을 올립니다.
1. 만들어진 빈 저장소 화면에서 **uploading an existing file** 링크를 누릅니다. (또는 **Add file → Upload files**)
2. 파일을 끌어다 놓습니다. 파일 이름은 반드시 **`index.html`** 이어야 합니다.
3. 아래쪽 **Commit changes**

> `Code.gs` 와 이 설명서는 올리지 않아도 됩니다. 올리는 파일은 `index.html` 하나면 충분합니다.

**D. Pages 켜기**
1. 저장소 위쪽 **Settings** → 왼쪽 메뉴 **Pages**
2. **Build and deployment → Source** 는 **Deploy from a branch**
3. **Branch** 는 **main**, 폴더는 **/ (root)** 를 고르고 **Save**

**E. 주소 확인** — 1~2분 뒤 같은 Pages 화면 위쪽에 **Your site is live at …** 가 나타납니다. 주소 모양은 보통 이렇습니다.
```
https://내깃허브아이디.github.io/inventory-app/
```
이 주소를 직원에게 공유하면 됩니다. 아직 안 열리면 2~3분 기다린 뒤 다시 열어 보세요.

**나중에 URL이나 설정을 바꿀 때**: 수정한 `index.html` 을 같은 방법(**Add file → Upload files**)으로 다시 올리면 같은 이름의 파일이 교체됩니다. 1~2분 뒤 반영됩니다.

### 6. 스마트폰에서 쓰기
- 위에서 만든 GitHub Pages 주소를 폰 브라우저로 엽니다.
- 상단 오른쪽에 **"연결됨"** 이 보이면 완성입니다. **"연결 실패"** 또는 **"연결 안 됨"** 이면 화면의 안내와 아래 [문제 해결]을 따르세요.
- 폰 홈 화면에 추가: 안드로이드(크롬) 점 3개 → 홈 화면에 추가 / 아이폰(사파리) 공유 → 홈 화면에 추가
- 구글 시트를 팀원에게 공유할 때는 **편집자** 권한을 줍니다.

> **보안 안내** — GitHub Pages(무료)로 올린 앱은 인터넷에 공개됩니다. `index.html` 안에 URL이 들어 있으므로 **주소를 아는 사람은 누구나** 앱을 열어 품목 조회·수정·삭제·청구서 생성을 할 수 있습니다(로그인 기능은 없습니다). 그래서 이 시스템에는 **소모품·재고 정보만** 넣고, 환자 개인정보는 절대 넣지 마세요. 주소가 외부에 알려진 것 같다면 [문제 해결]의 "주소 교체"를 따르세요.

## 우리 병원 품목 넣기
먼저 예제로 체험했다면 메뉴 **🏥 재고관리 → 🧹 예제 데이터 지우기**로 한 번에 지웁니다. (예제 품목과 체험하며 만든 기록만 지우며, 예제가 아닌 품목이 있으면 아무것도 지우지 않습니다.)

**방법 1. 앱에서 하나씩** — 앱의 **품목관리 → + 새 품목 추가**. 대분류(부서)와 소분류는 목록에서 고르거나 **새 이름을 직접 입력**해도 됩니다.

**방법 2. 구글 시트에 한꺼번에 붙여넣기** — 엑셀 등의 표를 `품목 마스터` 탭 **A2 칸부터** 붙여넣습니다. (머리글 제외)
열 순서: **대분류(부서) / 소분류 / 품목명 / 규격·단위 / 적정재고 / 현재재고 / 메모**
H(품목번호)와 I(상태)는 자동으로 채워집니다. 앱을 열거나 메뉴 **🔢 품목번호 채우기**를 누르면 새로 붙여넣은 줄에 번호가 붙습니다.

**알아 두세요**
- **대분류(부서)** 는 시트에 입력한 값이 앱 상단의 칩이 됩니다. 수술실, 병동처럼 쓰거나 A구역, B구역처럼 써도 됩니다.
- **소분류** 는 의약품·소모품·보조기·문구 같은 구분입니다. 자유롭게 정할 수 있습니다.
- **수량은 정수만** 입력하세요. `0.5`처럼 소수는 `0`으로 처리됩니다.
- 같은 이름의 품목도 번호로 구분되어 입력할 수 있지만, 알아보기 쉽게 이름이나 규격으로 구분하는 것을 권합니다.

## 사용 방법
1. **정기 재고파악**: 재고파악 → 실사할 대분류 선택 → 수량 입력 → 저장. 현재재고가 갱신되고 실사 기록이 남으며 다음 실사 예정일이 정해집니다.
2. **청구**: 물품청구 → 청구 대상 선택 → 수량 조정 → 청구서 생성 → 인쇄 / PDF 저장.
3. **입고**: 물품이 도착하면 입고 → 청구서 기준 → 청구서 선택 → 받은 수량 확인(기본값은 남은 수량) → 입고 저장. 청구서 없이 들어온 물품은 직접 입고를 쓰세요.
4. **PC에서 시트의 현재재고를 직접 고친 경우**: 실사 기록은 자동으로 남지 않으니, 메뉴 **📅 실사 완료 기록**으로 대분류를 입력해 실사일을 남기세요.
5. PC에서 부족 품목 전체를 한 번에 청구하려면 메뉴 **📋 물품 청구서 생성**을 쓰세요.

## 설치 후 점검표
- [ ] 앱 오른쪽 위에 "연결됨"
- [ ] 재고현황의 숫자(전체/정상/부족)가 `품목 마스터` 탭과 일치
- [ ] 재고파악에서 저장 → `실사 기록` 탭에 행이 생기고, 화면에 다음 실사 예정일이 나타남
- [ ] 물품청구에서 청구서 생성 → `물품 청구서` 탭에 행이 생기고, 인쇄 / PDF 저장이 열림
- [ ] 입고 → 청구서 기준으로 입고 저장 → `입고 기록` 탭에 행이 생기고 `품목 마스터`의 현재재고가 늘어남, 청구 내역이 "입고 완료"로 바뀜
- [ ] 품목관리에서 새 품목 추가 → `품목 마스터` 탭에 줄이 생기고 품목번호가 채워짐
- [ ] 구글 시트 상단에 🏥 재고관리 메뉴가 보임
- [ ] 파일 → 설정 → **시간대**가 (GMT+09:00) 서울인지 확인 (기록되는 날짜의 기준입니다)
- [ ] 팀원 폰에서도 열림

## 문제 해결
| 증상 | 원인 | 해결 |
|---|---|---|
| "연결 안 됨" | `index.html` 의 URL을 아직 안 넣음 | 4단계 |
| "연결 실패" | URL 오류 또는 권한 문제 | 3단계의 액세스 권한이 "모든 사용자"인지, 4단계의 URL이 맞는지 확인 |
| 품목이 안 보임 | 탭 이름을 바꿨거나 탭이 없음 | `setupSheets` 를 다시 실행하거나 탭 이름을 원래대로 |

## 주의사항
- **환자 개인정보는 입력하지 마세요.** 소모품·재고 관리용입니다.
- 웹 앱 URL을 아는 사람은 누구나 접근할 수 있습니다. 위 보안 안내를 꼭 읽어 주세요.
- 품목관리에서 현재고를 바로 고치면 실사 기록·입고 기록은 남지 않습니다. 정기 재고파악은 **재고파악**, 들어온 물품은 **입고** 화면을 쓰세요.
- 시트의 `품목 마스터` H열(품목번호)은 앱이 품목을 구분하는 번호입니다. 지우거나 바꾸지 마세요. (지워도 자동으로 다시 채워지지만, 지난 청구서와의 연결이 끊길 수 있습니다.)
