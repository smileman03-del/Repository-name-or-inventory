# 병원 소모품 재고관리 시스템 (구글 시트 + 스마트폰 앱)

구글 시트를 장부로 쓰고, 스마트폰에서 재고 확인·청구·주간 실사를 할 수 있는 시스템입니다.
엑셀이나 별도 서버가 필요 없고, 데이터는 사용자의 구글 시트에만 저장됩니다.

```
[구글 시트 (탭 4개)] ↔ [Apps Script (Code.gs)] ↔ [스마트폰 앱 (index.html)]
```

## 파일 구성
| 파일 | 역할 |
|---|---|
| `Code.gs` | 구글 시트 메뉴 + 앱과 통신하는 API |
| `index.html` | 스마트폰 앱 (파일 하나로 동작) |
| `README.md` | 이 설명서 |

필요한 것: 구글 계정, 스마트폰 또는 PC 브라우저. 설치 시간은 약 15분입니다.

## 주요 기능
- **현황**: 재고부족/정상/전체 개수, 구역별 필터, 품목명 검색, 품목 삭제
- **청구**: 재고부족 품목이 자동으로 표시됩니다. 체크하고 수량(−/+)을 조정해 제출하면 구글 시트에 기록됩니다.
- **주간실사**: "오늘 날짜로 전체 품목 불러오기" → 실사 수량 입력 → 저장하면 기록되고 현재재고가 갱신됩니다.
- **구글 시트 메뉴 (🏥 재고관리)**: 현황 대시보드, 주간실사 자동입력, 물품 청구서 생성, 품목 추가/삭제, 실시간 재고 대장 새로고침, 예제 데이터 지우기
- 앱에서는 재고 수량을 직접 고칠 수 없고 **주간실사로만** 바뀝니다. 여러 명이 쓸 때 실수를 막기 위해서입니다.

## 구글 시트의 탭 4개
설치하면 자동으로 만들어지니 직접 만들 필요가 없습니다. **탭 이름은 바꾸지 마세요.**

| 탭 | 내용 | 직접 입력? |
|---|---|---|
| `품목 마스터` | 우리 병원 품목 목록. 열: 품목명 / 보관위치 / 규격·단위 / 적정재고 / 현재재고 / 상태(자동) | **여기에 입력합니다** (A~E열). 상태 열은 자동으로 채워집니다. |
| `주간 재고 파악` | 주간 실사 기록이 쌓입니다 | 자동 기록 |
| `실시간 재고 대장` | **재고부족 품목만** 모아 보여줍니다. 품목 추가·삭제·실사 저장 때 자동으로 갱신됩니다. 처음엔 비어 있는 게 정상입니다. | 자동. 시트에서 재고를 직접 고쳤다면 메뉴 **🔄 실시간 재고 대장 새로고침** |
| `물품 청구서` | 청구서 기록 (청구번호별로 묶임) | 자동 기록 |

## 설치 순서

### 1. 구글 시트와 Apps Script 준비
1. 브라우저에 `sheets.new` 를 입력해 새 구글 시트를 만듭니다.
2. **확장 프로그램 → Apps Script** 를 엽니다.
3. 기존 코드를 모두 지우고 `Code.gs` 내용을 붙여넣은 뒤 저장(Ctrl+S)합니다.

### 2. 탭 만들기 (아래 둘 중 하나)
상단의 함수 선택 칸에서 함수를 고르고 ▶ 실행을 누릅니다.
- **`loadSampleData`** : 예제 품목 15개가 들어 있는 상태로 시작합니다. 먼저 체험해 보고 싶을 때 추천합니다.
- **`setupSheets`** : 빈 상태로 시작합니다.

처음 실행하면 권한 승인 창이 뜹니다. **"고급 → 안전하지 않음(이동) → 허용"** 을 차례로 누르세요. 끝나면 구글 시트에 탭 4개가 생기고, 시트를 새로고침하면 상단에 🏥 재고관리 메뉴가 나타납니다.

### 3. 웹 앱으로 배포
1. **배포 → 새 배포 → 톱니바퀴 → 웹 앱**
2. 실행 사용자: **나** / 액세스 권한: **모든 사용자** (반드시)
3. 배포를 누르면 나오는 **웹 앱 URL을 복사**해 메모장에 저장합니다.

**연결 테스트**: 브라우저 주소창에 `복사한URL?action=getMaster` 를 열었을 때 품목 데이터(JSON)가 보이면 성공입니다.

### 4. 앱에 URL 연결
`index.html` 을 메모장으로 열어 `SCRIPT_URL_HERE` 를 복사한 URL로 바꾸고 저장합니다. 메모장의 "모두 바꾸기"를 써도 됩니다.
```js
var SCRIPT_URL = "https://script.google.com/macros/s/....../exec";
```

### 5. 스마트폰에서 쓰기
- `index.html` 을 웹에 올려 주소를 만들고 직원에게 공유합니다. (예: GitHub Pages — 저장소 생성 → Settings → Pages → Deploy from a branch → main)
- 앱 상단에 **"실시간 연결됨"**(초록)이 보이면 완성입니다. **"오프라인"**(빨강)이면 URL과 배포 설정을 확인하세요.
- 폰 홈 화면에 추가: 안드로이드(크롬) 점 3개 → 홈 화면에 추가 / 아이폰(사파리) 공유 → 홈 화면에 추가
- 구글 시트를 팀원에게 공유할 때는 **편집자** 권한을 줍니다.

> **보안 안내** — 무료 호스팅(GitHub Pages 등)은 인터넷에 공개됩니다. `index.html` 안에 URL이 들어 있으므로 **주소를 아는 사람은 누구나** 앱을 열어 품목 조회·삭제·청구서 제출을 할 수 있습니다(로그인 기능은 없습니다). 그래서 이 시스템에는 **소모품·재고 정보만** 넣고, 환자 개인정보는 절대 넣지 마세요. 주소가 외부에 알려진 것 같다면 [문제 해결]의 "주소 교체"를 따르세요.

## 우리 병원 품목 넣기
1. 예제로 체험했다면 메뉴 **🏥 재고관리 → 🧹 예제 데이터 지우기**로 한 번에 지웁니다. (예제 품목과 체험하며 만든 기록만 지우며, 예제가 아닌 품목이 있으면 아무것도 지우지 않습니다.)
2. 엑셀 등에서 품목 표를 복사해 `품목 마스터` 탭 **A2 칸부터 붙여넣습니다.** (머리글 제외, 열 순서: 품목명 / 보관위치 / 규격·단위 / 적정재고 / 현재재고)
3. F열(상태)은 자동입니다. 건드리지 마세요.

**꼭 지켜 주세요**
- **품목명은 겹치면 안 됩니다.** 같은 이름이 두 줄이면 어느 줄인지 알 수 없어 앱이 경고를 띄우고 실사 저장·삭제를 막습니다. 규격이 다르면 `거즈 4x4`, `거즈 10x10`처럼 이름을 구분하세요.
- **수량은 정수만** 입력하세요. `0.5`처럼 소수는 `0`으로 처리됩니다.
- **보관위치**가 앱의 구역 탭이 됩니다. 수술실, 처치실처럼 쓰거나 A구역, B구역처럼 써도 됩니다.

## 사용 방법
1. 주간실사 탭에서 실사 수량을 입력해 저장합니다. 현재재고가 갱신됩니다.
2. 청구 탭에 재고부족 품목이 자동으로 나타납니다. 수량을 조정해 제출합니다.
3. PC에서는 메뉴 **📋 물품 청구서 생성**으로 부족 품목 전체를 한 번에 청구할 수도 있습니다.

## 설치 후 점검표
- [ ] 앱 상단에 "실시간 연결됨"
- [ ] 현황 탭의 숫자(부족/정상/전체)가 `품목 마스터` 탭과 일치
- [ ] 청구 탭에서 제출 → `물품 청구서` 탭에 행이 생김
- [ ] 주간실사 저장 → `주간 재고 파악` 탭에 기록, `품목 마스터`의 현재재고 갱신
- [ ] 구글 시트 상단에 🏥 재고관리 메뉴가 보임
- [ ] 팀원 폰에서도 열림
- [ ] 파일 → 설정 → **시간대**가 (GMT+09:00) 서울인지 확인 (기록되는 날짜의 기준입니다)

## 문제 해결
| 증상 | 원인 | 해결 |
|---|---|---|
| "오프라인" 빨간색 | URL 오류 또는 권한 문제 | 3단계의 액세스 권한이 "모든 사용자"인지 확인, 4단계의 URL 확인 |
| 품목이 안 보임 | 탭 이름을 바꿨거나 탭이 없음 | `setupSheets` 를 다시 실행하거나 탭 이름을 원래대로 |
| "탭이 없습니다" 오류 | `setupSheets` 를 실행하지 않음 | 2단계 실행 |
| 코드를 고쳤는데 그대로 | 재배포를 안 함 | 배포 → **새 배포** (같은 배포를 수정만 하면 반영되지 않음) |
| 메뉴(🏥)가 안 보임 | 시트를 새로고침하지 않음 | 구글 시트를 새로고침(F5). 그래도 없으면 Apps Script에서 `onOpen` 실행 |
| 앱에 노란 경고 "품목명이 중복" | 같은 이름의 품목이 2줄 이상 | `품목 마스터`에서 이름을 서로 다르게 수정 |
| 실시간 재고 대장이 비어 있음 | 부족 품목이 없거나 아직 갱신 전 | 메뉴 🔄 새로고침 |
| 새 줄의 상태 열이 비어 있음 | 현재재고를 입력하지 않음 | 현재재고(E열)를 입력하면 자동으로 채워집니다 |
| **주소 교체** (URL이 외부에 알려졌을 때) | — | 배포 → **새 배포**로 새 URL을 만들고, **배포 관리**에서 옛 배포를 **보관처리**한 뒤 `index.html`의 URL을 바꿔 다시 올립니다 |

## 주의사항
- **환자 개인정보는 입력하지 마세요.** 소모품·재고 관리용입니다.
- 웹 앱 URL을 아는 사람은 누구나 접근할 수 있습니다. 위 보안 안내를 꼭 읽어 주세요.
- 앱에서는 재고를 직접 고칠 수 없습니다. 재고 변경은 주간실사로 합니다. (PC에서 시트의 현재재고를 직접 고치는 것은 가능합니다.)
