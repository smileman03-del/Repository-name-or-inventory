# 병원 소모품 재고관리 시스템 (엑셀 + 구글 시트 + 스마트폰 앱)

엑셀로 관리하던 소모품 재고를 구글 시트에 올리고, 스마트폰에서 재고 확인·청구·주간 실사를 할 수 있는 시스템입니다.
서버 비용이 없고, 데이터는 사용자의 구글 시트에만 저장됩니다.

```
[엑셀 + VBA 매크로] → [구글 시트 4개 탭] ↔ [Apps Script] ↔ [스마트폰 앱(index.html)]
```

## 파일 구성
| 파일 | 역할 |
|---|---|
| `소모품관리대장_템플릿.xlsx` | 엑셀 템플릿 (탭 4개 + 사용방법, 가상의 예시 품목 12개) |
| `재고관리매크로.bas` | 엑셀용 VBA 매크로 (주간실사 입력, 청구서 생성) |
| `Code.gs` | 구글 시트 메뉴 + 웹앱 API |
| `index.html` | 스마트폰 앱 |

> 예시 품목은 **모두 가상의 데이터**입니다. 지우고 우리 병원 품목을 입력해서 쓰세요.

## 주요 기능
- **현황**: 재고부족/정상/전체 개수, 구역별 필터, 품목명 검색(한글 입력 최적화), 품목 삭제
- **청구**: 재고부족 품목 자동 표시, 체크박스와 수량 −/+ 조정, 제출하면 구글 시트에 기록
- **주간실사**: "오늘 날짜로 전체 품목 불러오기" → 수량 입력 → 저장하면 기록되고 현재재고 갱신
- **구글 시트 메뉴(🏥 재고관리)**: PC에서 시트를 열면 상단에 생김 (현황, 주간실사 자동입력, 청구서 생성, 품목 추가/삭제)
- 재고 수량은 **앱에서 직접 수정할 수 없고** 주간실사로만 바뀝니다. 여러 명이 쓸 때 실수를 막기 위해서입니다.

## 설치 순서

### 1. 엑셀 준비
1. `소모품관리대장_템플릿.xlsx`을 열고 **[품목 마스터]** 탭에 우리 병원 품목을 입력합니다.
   - 열: 품목명 / 보관위치 / 규격·단위 / 적정재고 / 현재재고 / 상태(수식, 자동)
   - **보관위치**가 앱의 구역 탭이 됩니다. (수술실, 처치실 등 원하는 이름으로 바꾸거나 A구역~E구역처럼 써도 됩니다)
2. 구글 시트에 올릴 파일은 **반드시 `.xlsx`** 로 저장하세요. (`.xlsm`은 구글 시트 업로드가 막힙니다)

### 2. 구글 시트 만들기
1. 브라우저에 `sheets.new` 입력
2. 파일 → 가져오기 → 업로드 → 엑셀 파일 선택 → **"스프레드시트 대체"** → 가져오기
3. 탭 이름이 아래와 **띄어쓰기까지 똑같은지** 확인합니다.

   `품목 마스터` / `주간 재고 파악` / `실시간 재고 대장` / `물품 청구서`

> 업로드가 안 되면 엑셀에서 전체 복사(Ctrl+A, Ctrl+C) → 구글 시트 A1에 **Ctrl+Shift+V**(값만 붙여넣기)

### 3. Apps Script 배포
1. 구글 시트 → 확장 프로그램 → Apps Script
2. 기존 코드를 모두 지우고 `Code.gs` 내용을 붙여넣은 뒤 저장(Ctrl+S)
3. 함수 선택에서 **`onOpen`** → ▶ 실행 → 권한 승인
   (화면에 "고급 → 안전하지 않음(이동) → 허용"이 나오면 차례로 누릅니다)
4. 배포 → 새 배포 → 톱니바퀴 → **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (반드시!)
5. 배포 후 나온 **URL을 복사**해 메모장에 저장합니다.

**연결 테스트** (필수): 브라우저 주소창에 `복사한URL?action=getMaster` 를 열었을 때 품목 데이터(JSON)가 보이면 성공입니다.

### 4. 앱에 URL 연결
`index.html`을 메모장으로 열어 `SCRIPT_URL_HERE`를 복사한 URL로 바꾸고 저장합니다.
```js
var SCRIPT_URL = "https://script.google.com/macros/s/....../exec";
```

### 5. 스마트폰에서 쓰기
- `index.html`을 GitHub Pages 등에 올려 주소를 만들고 직원에게 공유합니다.
  (깃허브 저장소 생성 → Settings → Pages → Deploy from a branch → main)
- 앱 상단에 **"실시간 연결됨"** (초록)이 보이면 완성입니다. **"오프라인"**(빨강)이면 URL과 배포 설정을 확인하세요.
- 폰 홈 화면에 추가: 안드로이드(크롬) 점 3개 → 홈 화면에 추가 / 아이폰(사파리) 공유 → 홈 화면에 추가
- 구글 시트를 팀원에게 공유할 때는 **편집자** 권한을 줍니다.

### 6. 엑셀 매크로 설치 (선택)
엑셀에서 매크로로도 주간실사·청구서를 만들고 싶을 때만 합니다.
1. 파일 → 옵션 → 보안 센터 → 보안 센터 설정 → 매크로 설정 → **모든 매크로 포함**
2. `재고관리매크로.bas`를 **메모장으로 열어 전체 복사**
3. 엑셀에서 **Alt + F11** → 삽입 → 모듈 → 붙여넣기 → 저장 (매크로가 있는 파일은 `.xlsm`으로 저장)
4. 개발 도구 탭 → 삽입 → 단추(양식 컨트롤) → 시트에 그리고 매크로 연결
   - 주간실사 버튼: `Weekly_Input`
   - 청구서 버튼: `Request_Generate`

> 개발 도구 탭이 없으면: 파일 → 옵션 → 리본 사용자 지정 → 개발 도구 체크
> 매크로 함수 이름은 반드시 영문이어야 합니다. 한글로 바꾸면 오류가 납니다.

## 설치 후 점검표
- [ ] 앱 상단에 "실시간 연결됨"
- [ ] 현황 탭의 숫자(부족/정상/전체)가 시트와 일치
- [ ] 청구 탭에서 제출 → `물품 청구서` 탭에 행이 생김
- [ ] 주간실사 저장 → `주간 재고 파악` 탭에 기록, `품목 마스터` 현재재고 갱신
- [ ] 구글 시트 상단에 🏥 재고관리 메뉴가 보임
- [ ] 팀원 폰에서도 열림

## 문제 해결
| 증상 | 원인 | 해결 |
|---|---|---|
| "오프라인" 빨간색 | URL 오류 또는 권한 문제 | 재배포 → 액세스 "모든 사용자" → **새 URL**로 교체 |
| 품목이 안 보임 | 탭 이름이 다름 | 탭 4개 이름을 띄어쓰기까지 확인 |
| 코드를 고쳤는데 그대로 | 재배포를 안 함 | 배포 → **새 배포** (같은 배포를 수정만 하면 반영되지 않음) |
| 엑셀 업로드 안 됨 | `.xlsm` 형식 | `.xlsx`로 저장하거나 복사·붙여넣기 |
| 매크로 인코딩 오류 | 한글 함수명 | 함수명을 영문으로 |
| 메뉴(🏥)가 안 보임 | `onOpen` 미실행 | Apps Script에서 `onOpen` 한 번 실행 후 시트 새로고침 |

## 주의사항
- **환자 개인정보는 입력하지 마세요.** 소모품·재고 관리용입니다.
- 웹 앱 URL을 아는 사람은 누구나 접근할 수 있습니다. URL은 직원에게만 공유하세요.
- 앱에서는 재고를 직접 고칠 수 없습니다. 재고 변경은 주간실사로만 합니다.
