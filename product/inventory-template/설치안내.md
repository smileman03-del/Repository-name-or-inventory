# 병원 재고관리 시스템 설치 안내

구글 시트를 데이터베이스로 쓰는 모바일 재고관리 웹앱입니다. 별도 서버와 월 비용이 없습니다.

## 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면(앱). 스마트폰/PC 브라우저에서 사용 |
| `Code.gs` | 구글 시트와 앱을 연결하는 백엔드 |

## 주요 기능
- 부서별·분류별 재고 현황과 부족 품목 표시
- 2주 단위 재고 실사(부서별), 실사 이력 기록
- 부족 품목 기준 청구서 자동 생성과 이력 조회
- 품목 추가·수정·삭제

## 설치 (약 10분)

### 1단계. 구글 시트 만들기
1. 구글 드라이브에서 새 스프레드시트를 만듭니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.

### 2단계. 백엔드 붙여넣기
1. 기본 코드를 모두 지우고 `Code.gs` 내용을 붙여넣은 뒤 저장합니다.
2. 상단 함수 선택에서 **`setupSheets`**를 고르고 **실행**합니다. 권한 요청이 뜨면 허용합니다.
3. (선택) **`loadSampleData`**를 실행하면 샘플 품목 9개가 들어갑니다. 써 보고 시트에서 지우면 됩니다.

### 3단계. 웹앱으로 배포
1. **배포 → 새 배포 → 유형: 웹 앱**
2. 실행 사용자 **나**, 액세스 권한 **모든 사용자**를 선택하고 배포합니다.
3. 발급된 **웹 앱 URL**을 복사합니다.

### 4단계. 앱에 연결
1. `index.html`을 메모장으로 엽니다.
2. `SCRIPT_URL_HERE`를 찾아 복사한 URL로 바꿉니다.
   ```js
   const SCRIPT_URL = "https://script.google.com/macros/s/....../exec";
   ```
3. 저장한 뒤 브라우저로 열면 상단에 **연결됨**이 표시됩니다.

### 5단계. 직원들과 공유
- `index.html`을 GitHub Pages나 사내 공유 폴더 등에 올리고 주소를 직원에게 알려줍니다.
- 스마트폰에서는 브라우저 메뉴의 **홈 화면에 추가**를 쓰면 앱처럼 쓸 수 있습니다.

## 커스터마이즈
- **부서명 변경**: `index.html`의 `const DEPTS = [...]` 를 수정합니다.
- **병원명 표시**: `index.html`에서 `(병원명)`을 찾아 바꿉니다.
- **분류 순서**: `const CAT_ORDER = [...]`

## 자주 묻는 문제
| 증상 | 해결 |
|---|---|
| "연결 안 됨" | `SCRIPT_URL`이 아직 `SCRIPT_URL_HERE`인지 확인 |
| "연결 실패" | 배포 시 액세스 권한을 **모든 사용자**로 했는지 확인. 코드를 고쳤다면 **새 배포**가 필요 |
| 시트가 없다는 오류 | `setupSheets`를 먼저 실행 |

## 주의사항
- 환자 개인정보는 입력하지 마세요. 이 시스템은 소모품·재고 관리용입니다.
- 웹 앱 URL을 아는 사람은 누구나 접근할 수 있으므로, URL은 직원에게만 공유하세요.
