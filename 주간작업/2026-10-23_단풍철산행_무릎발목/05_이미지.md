# 05. 이미지 — 단풍철 산행 후 무릎·발목

## 운영자 확인 필요
1. **이미지를 확정하지 못했어요.** 이 세션의 Unsplash 연결이 "이메일 주소가 인증되지 않았다"는 오류로 막혀서(검색 3회 모두 같은 오류) 사진을 찾지 못했어요. Unsplash 계정의 이메일 인증을 마치면 이 단계를 다시 할 수 있어요.
2. 다른 방법으로 일반 웹 검색을 쓰면 사진 후보는 찾을 수 있지만, 사이트에 직접 접속할 수 없어서 **라이선스(상업적 이용·수정 가능 여부·출처 표시 조건)를 확인하지 못해요.** 규칙상 이용 조건을 확인하지 못한 이미지는 추천하지 않아서 특정 사진을 고르지 않았어요.
3. 아래 중 하나를 골라 주세요.
   - (가) 운영자가 직접 찍거나 구글 이미지 생성 도구로 만든 이미지 사용(아래 프롬프트 참고, 운영자가 전에 쓰던 방식)
   - (나) 운영자가 Unsplash·Pexels·Pixabay에서 아래 검색어로 직접 골라서 라이선스 확인 후 사용
   - (다) Unsplash 이메일 인증 후 다시 요청
   - (라) 이미지 없이 발행

## 구글 이미지 생성 도구로 직접 만들기 (운영자 방식, 2026-10-17 추가)
운영자가 전에도 구글에서 이미지를 만들어 썼다고 알려 왔어요. 구글의 이미지 생성 도구(예: Gemini)로 **운영자가 직접 만든 이미지**는 절대 규칙 3의 허용 항목(③ 운영자가 직접 만든 것)에 해당해요. 아래 프롬프트를 그대로 붙여넣어 만들어 보세요. 모든 프롬프트에는 "글자 없음, 로고 없음, 사람 얼굴 없음"을 넣었어요.

| 자리 | 프롬프트(한국어, 그대로 붙여넣기) |
|---|---|
| 이미지 1 | 단풍이 붉고 노랗게 물든 가을 산길 풍경 사진. 낙엽이 깔린 완만한 등산로, 따뜻한 오후 햇살. 가로 비율. 사람과 얼굴, 글자, 로고, 간판은 넣지 말 것. |

### 만든 뒤 확인할 것
1. 사람 얼굴이 어색하게 들어갔거나 글자·로고가 생기지 않았는지, 병원·치료 장면처럼 보이지 않는지 봐 주세요. 있으면 다시 만들기.
2. 등산 장비를 만들면 형태가 이상하게 나올 수 있어요(스틱이 휘거나 발이 어색한 경우). 문제가 있으면 장비는 빼고 풍경만 만드세요.
3. 이 글은 의학 정보라서 **실제 사진처럼 보이는 AI 이미지**임을 독자가 오해하지 않게, 네이버에 AI 생성 이미지 표시 규정이 있으면 발행 전에 확인해서 따라 주세요(이 세션에서는 네이버 정책을 확인하지 못했어요).
4. 구글 **이미지 검색**에서 찾은 사진을 가져오는 방식이라면 저작권이 있는 사진이 많아서 쓰면 안 돼요. 이미지 생성 도구로 만든 것만 쓰세요.
5. 완성한 이미지는 06_최종본.md의 📷 줄 위치에 넣고, 이미지 사용 목록에 "운영자가 구글 이미지 생성 도구로 직접 생성"이라고 적어 주세요.

## 피해야 할 이미지
- 환자·치료 장면처럼 보이는 사진, 병원·장비를 연상시키는 사진, 치료 전후를 연상시키는 이미지

- 다른 블로그·언론·병원 사이트에서 가져온 이미지(출처를 적어도 사용 금지)
