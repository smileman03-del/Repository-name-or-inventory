# 천안본정형외과 블로그 자동화

사용법: Claude Code에서 `/blog 겨울철 어깨 통증 원인과 관리`

흐름: 조사팀 → 분석팀 → 작성팀 → 이미지팀 → 검수팀 → (사람 확인) → 네이버 블로그 발행

- 에이전트: `.claude/agents/blog-*.md`  /  실행 명령: `.claude/commands/blog.md`
- 설정: `blog/config/` (스타일, 의료광고 체크리스트)
- 결과: `blog/output/<주제>/06_publish.md` + `images/`

## 네이버 블로그 발행에 대해
네이버는 공식 글쓰기 API를 제공하지 않아, 로그인 자동화(브라우저 조작)는 약관 위반·계정 제한·캡차 위험이 있습니다.
현재는 검수 통과 패키지를 만들고 담당자가 에디터에 붙여넣어 발행하는 반자동 방식입니다.
의료광고는 최종 책임이 병원에 있으므로 사람 확인 단계를 유지하세요.
